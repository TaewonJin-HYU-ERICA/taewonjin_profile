## Public Repository Policy

This repository only contains material cleared for public release:

- project summaries
- public figures
- cleaned or example code
- reproducible demos
- selected references
- publication or preprint links

This repository must not contain raw data, unpublished manuscripts, confidential notes, reviewer responses, private analysis outputs, or copyright-sensitive materials.
